# Java Basic Calculator

A simple console-based calculator application written in Java. It accepts two integers and a mathematical operator from the user, processes the calculation, and displays the result safely.

## 🚀 Features
- Supports basic arithmetic operators: `+`, `-`, `*`, `/`, `%`
- Prevents runtime crashes with built-in validation for **division by zero** (`/ 0`)
- Prevents runtime crashes for **modulus by zero** (`% 0`)
- Handles invalid operator inputs gracefully

## 💻 How to Run
1. Make sure you have **Java JDK** installed on your system.
2. Open your terminal or command prompt in the project directory.
3. Compile the Java file:
   ```bash
   javac homework_1.java
   ```
4. Run the program:
   ```bash
   java homework_1
   ```

## 🛠️ Technologies Used
- **Language:** Java 8+
- **Input handling:** `java.util.Scanner`
- **Logic:** Conditional constructs (`if-else`)
